# Privacy Policy — FC Norrsken Bokningskalender

**Effective date:** September 22, 2026

FC Norrsken Bokningskalender is a browser extension that improves the presentation of FC Norrsken's public SportAdmin calendar.

## Data processed

The extension reads calendar information already displayed on `https://www.fcnorrsken.se/kalender/`, including dates, times, team names, activity descriptions, venues, and booking areas. This information is processed locally in the user's browser to display filters, a timeline, and booking-conflict indicators.

## Local storage

The extension stores only the following preferences in the browser's local storage for the FC Norrsken website:

- the selected calendar view; and
- user-configured default match durations by game format.

These preferences remain on the user's device unless the user clears the website's stored data.

## Data collection and sharing

The extension does not collect, transmit, sell, or share personal information or calendar information. It does not use analytics, advertising, tracking, remote code, or external APIs. No data is sent to the developer or any third party by the extension.

The FC Norrsken website and SportAdmin remain responsible for their own processing of information. Their privacy terms apply independently when the user visits the calendar website.

## Permissions and site access

The extension is limited to FC Norrsken calendar pages under `https://www.fcnorrsken.se/kalender/`. This access is required to read and enhance the calendar shown on those pages. The extension requests no optional Chrome API permissions.

## Changes to this policy

This policy may be updated if the extension's data practices change. The effective date above identifies the latest version.
