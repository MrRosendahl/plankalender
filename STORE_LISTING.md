# Chrome Web Store Listing

Use this document as the source for the Chrome Web Store Developer Dashboard fields. The listing language should be **Swedish** because the extension and its intended audience are Swedish.

## Product details

### Name

FC Norrsken Bokningskalender

### Summary

Visar FC Norrskens bokningar i en tidsmatris och upptäcker krockar mellan bokningsytor.

### Detailed description

FC Norrsken Bokningskalender gör föreningens SportAdmin-kalender enklare att överblicka.

Tillägget visar kalenderns bokningar i en tydlig tidsmatris där tider visas lodrätt och bokningsytor visas som kolumner. Kalendern kan filtreras efter sektion, vecka, anläggning, bokningsyta och aktivitetstyp.

Överlappande bokningar på samma datum, anläggning och bokningsyta markeras som krockar. Tillägget tar hänsyn till helplaner, halvplaner och fjärdedelsplaner. Om en match saknar sluttid kan sluttiden beräknas från en lokalt konfigurerad standardtid för spelformen.

Funktioner:

- tidsmatris per dag och anläggning;
- filter för sektion, period, anläggning, bokningsyta och aktivitetstyp;
- upptäckt och tydlig markering av bokningskrockar;
- detaljerad information när en bokning väljs;
- växling mellan den förbättrade kalendern och SportAdmins originalvy; och
- lokalt sparade inställningar för kalendervy och standardtider.

Tillägget fungerar endast på FC Norrskens kalender med kalender-ID 370929. All bearbetning sker lokalt i webbläsaren. Tillägget skickar inte kalenderuppgifter eller personuppgifter till utvecklaren eller tredje part.

Detta är ett fristående hjälpmedel för kalenderpresentation. SportAdmin ansvarar för kalenderns ursprungliga innehåll och tillgänglighet.
